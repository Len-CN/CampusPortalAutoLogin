# 已知限制

- 仅支持 Windows 10/11 x64 和当前已实现的校园门户协议；不同学校即使页面相似，也可能使用不同参数、加密或认证流程。
- 必须在真实校园网手工验收。开发机测试、模拟响应和 `--smoke-test` 不能证明目标网络可正常认证。
- 门户出现验证码时不会自动识别或绕过，须在原门户浏览器页面人工输入。
- 检测到未知门户、页面结构变化或需要附加运营商密码时，程序会停止自动尝试。
- 网络变化事件可能由 VPN、虚拟网卡、休眠恢复或频繁切换网络重复触发；协调器会尽量合并请求，但网络环境仍会影响登录时机。
- DPAPI `CurrentUser` 加密的凭据不能跨 Windows 用户、跨系统或跨电脑迁移。
- .NET 托管字符串受垃圾回收管理，无法保证密码在内存中的所有副本都被立即清零。
- 任务计划程序可能被学校或单位的组策略禁用；此时登录时启动功能无法使用，需要管理员调整策略。
- 卸载只清理当前执行卸载的 Windows 账户数据，不枚举其他用户 Profile。通过 UAC 使用另一管理员账户卸载时，原使用者数据会保留，需由该用户手动删除。配置凭据和日志默认均保留。
- 本程序无遥测。诊断问题需要用户自行查看并按需提供已经检查、脱敏的日志。

# 配置说明

## 存储位置

当前 Windows 用户的配置位于 `%LOCALAPPDATA%\CampusPortalAutoLogin`：

- `config.json`：普通设置，不保存明文密码。
- `secrets.dat`：使用 Windows DPAPI `CurrentUser` 加密的凭据。
- `logs`：运行日志目录。

DPAPI 数据只能由加密它的同一 Windows 用户解密。更换 Windows 账号、重装系统或复制 `secrets.dat` 到另一台电脑后，需要重新输入密码。

## 默认设置

| 设置 | 默认值 |
| --- | --- |
| 服务商 | 中国电信（`telecom`） |
| 登录时启动 | 开启 |
| 网络变化触发 | 开启 |
| 程序启动后执行一次 | 开启 |
| 定时登录 | 开启，07:00 |
| 周期检测 | 关闭 |
| 检测间隔 | 45 秒 |

首次接受隐私说明并保存有效凭据前，不会自动发起认证请求。

## 自启动

自启动使用 Windows 任务计划程序，任务名为 `CampusPortalAutoLogin-<当前用户SID>`，按当前用户交互登录触发并延迟 10 秒运行。旧版本可能使用固定名称 `CampusPortalAutoLogin`。保存设置时使用 Task Scheduler 的 `CREATE_OR_UPDATE` 原子更新任务，不会先删除旧任务再创建。创建或更新任务需要当前用户具备操作本人计划任务的权限；受学校管控策略限制的电脑可能拒绝该操作。

卸载会用管理员权限检查固定名称及 SID 后缀任务，但只删除动作路径精确指向本次安装目录可执行文件的任务。若组织策略阻止删除，请由管理员在任务计划程序库中核对动作路径后手动删除。

## 命令行参数

- `--shutdown`：通过当前用户的 Windows 命名事件通知已运行实例退出，供升级安装使用。
- `--remove-autostart`：删除当前用户的自启动任务后退出。
- `--smoke-test <目录>`：将隔离预览渲染到指定目录；不保存真实配置、不修改自启动，也不发送网络请求。

请勿把 `--smoke-test` 的输出目录放在正式配置目录中。

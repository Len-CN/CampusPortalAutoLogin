# 1.0.3 光效跟随、文字清晰度与成功后清日志

鼠标光效由 34 DIP 放大至 96 DIP，移到文字下方。原实现每个鼠标事件都重建两条 240 毫秒缓动；现在只保存最新坐标，在 WPF 渲染帧统一更新，停止移动后退订渲染回调，离开、隐藏、最小化或关闭窗口时清理。

移除整张卡片上的 DropShadowEffect 与文字随卡片悬浮位移，以背景绘制阴影和高光；按钮的装饰背景与文字前景分离。窗口启用布局舍入、像素对齐与 Display 字体度量，透明表面使用 Grayscale 抗锯齿，减少离屏纹理和小数坐标带来的发虚。窗口底色仍为 82% 不透明，标题栏背景连续。

仅 LoginState.Success 触发清空，并在登录互斥释放前完成，避免下一轮登录开始后被清掉日志。Online、失败、取消等状态保留日志。磁盘清理与界面刷新同步，普通追加保留用户选择。清理 IO 异常不会改变成功结果，仍显示警告供排查。

验证：35 项核心/协议测试通过，Release 构建 0 警告 0 错误，发布版 WPF 隔离检查通过。预览与模拟指针检查不代表实际显示器上的稳定帧率，未执行真实账号认证。

# 隐私说明

校园网自动登录只为完成用户主动配置的校园网连通性检测和认证而处理数据。

## 本地数据

用户名和普通设置保存在 `%LOCALAPPDATA%\CampusPortalAutoLogin\config.json`。密码保存在同目录的 `secrets.dat`，由 Windows DPAPI `CurrentUser` 加密，只能由同一 Windows 用户解密。日志保存在 `logs` 子目录，用于本地排错。

程序没有遥测、行为分析或崩溃数据上报，不向开发者服务器发送配置、凭据或日志。认证时，必要字段会按校园门户协议发送到当前检测到的校园门户。

## 安全边界

DPAPI 能保护磁盘上的凭据，但无法防止已经控制当前 Windows 用户会话的程序读取数据。密码进入 .NET 代码后可能短暂存在于托管字符串中；受运行时内存管理机制限制，无法保证所有内存副本被立即、完整地清零。

首次运行必须确认本说明并保存有效凭据；在此之前程序不会发送认证请求。遇到验证码、未知门户或需要附加运营商密码时，程序停止自动尝试，验证码须在原校园门户浏览器页面人工输入。

仓库中的协议样本已经脱敏，不包含可用的真实账号或密码。

## 删除数据

每次实际登录成功后，程序自动删除 `logs` 中的 JSONL 日志文件并刷新日志窗口；不删除配置、密码或其他类型文件。仅检测到已联网不会触发清空，失败记录仍按设置的保留期清理。日志被其他程序占用时会记录清理失败提示。

卸载会分别询问是否删除配置凭据和日志，默认都保留，以便升级或重装。明确选择删除后，只处理当前卸载账户的固定应用数据位置；不会枚举或跨权限删除其他 Windows 用户的数据。其他用户需要登录自己的账户、退出程序，再手动删除 `%LOCALAPPDATA%\CampusPortalAutoLogin`。删除过程拒绝跟随重解析点，失败时会显示需要手动检查的目录。

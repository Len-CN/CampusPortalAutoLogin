# 1.0.1 修复说明

## 校园网 pageInfo 空响应

用户提供日志显示：首页 `status=200 len=47959`，随后 `pageInfo status=200 len=0`，解析中断。

2026-09-23 在当前校园门户读取元数据，未提交账号密码，得到以下对照：

| 请求变化 | HTTP 状态 | 正文字符数 | JSON |
| --- | --- | --- | --- |
| 无 User-Agent | 200 | 0 | 否 |
| 只添加 Referer | 200 | 0 | 否 |
| 添加 Referer 和 Origin | 200 | 0 | 否 |
| 只添加 Accept | 200 | 0 | 否 |
| 只添加浏览器 User-Agent | 200 | 2433 | 是 |
| 浏览器请求头组合 | 200 | 2433 | 是 |

该门户会在缺少浏览器标识时返回空正文。公共 HTTP 请求路径现为缺少 User-Agent 的请求补充经实测可用的 Windows 浏览器标识，覆盖探测、首页、pageInfo、getServices 和登录。未改动登录字段编码或加密规则。

若接口仍返回空正文，显示接口名称与“空正文”提示，并按现有有限重试策略处理；不跳过元数据检查，不降级加密，不继续提交密码。

当时系统已联网，无法重现未认证门户的完整真实登录；修复已经通过现场元数据对照与完整离线登录回归验证。没有将离线通过宣称为真实账号认证成功。

## 背景光晕

原版只有打开窗口时的 Blur In，没有持续运动。现为设置和日志窗口添加低速往复位移，每秒最多 24 帧；窗口最小化、隐藏、高对比度或系统减少动画时停止，恢复显示后重新开始，关闭时移除动画与系统事件订阅。保留 82% 底层不透明度和标题栏连续背景。

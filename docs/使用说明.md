# 使用说明

## 安装与首次运行

支持 Windows 10/11 x64。安装程序需要管理员权限，将自包含版本安装到 `C:\Program Files\CampusPortalAutoLogin`，无需另行安装 .NET 运行时。

首次运行会显示隐私说明并打开设置。接受隐私说明、填写校园网用户名和密码并保存之前，程序不会发送认证请求。默认服务商为中国电信，定时登录时间为 07:00，网络检测间隔为 45 秒；登录时启动、网络变化触发、启动后执行一次和定时登录默认开启，周期检测默认关闭。

程序平时驻留系统托盘。托盘菜单提供“立即登录”“设置”“查看日志”“关于”和“退出”。窗口关闭后请从托盘菜单再次打开或退出。

## 日常使用

1. 在设置中填写账号、密码并选择服务商。
2. 保存设置后，可用“立即登录”验证配置。
3. 日志位于 `%LOCALAPPDATA%\CampusPortalAutoLogin\logs`，排查失败时先查看最新日志。

从 1.0.5 起，日志固定保存在 `logs/latest.jsonl`，只保留最近一轮探测与登录记录。新一轮开始时覆盖上一轮，并清理旧版日期日志；同轮重试继续追加，成功、失败、取消及已联网结果均保留到下一轮。合并到正在进行的流程的触发不会覆盖本轮日志。日志窗口同步刷新，也可手动清空。文件被占用导致覆盖失败时显示警告，不影响认证结果。旧配置中的日志保留天数字段不再参与清理。

遇到门户验证码时，程序会停止自动尝试；请在原校园门户浏览器页面人工输入验证码并完成认证。检测到未知门户，或门户要求附加运营商密码等未支持字段时，也会停止自动尝试，避免反复提交错误凭据。

## 升级与卸载

可直接运行新版安装程序覆盖升级。升级会先请求旧程序退出，并由 Windows Restart Manager 处理仍占用的文件；配置、凭据和日志会保留。

卸载开始前会请求驻留应用退出，并用 Windows Restart Manager 关闭正在使用本次安装路径的程序，再检查相同可执行路径的进程是否已全部退出。等待 15 秒仍未退出时会取消卸载并明确提示，不会按进程名强制结束其他安装路径的程序。卸载程序只删除名称为 `CampusPortalAutoLogin` 或 `CampusPortalAutoLogin-<用户SID>`、且执行路径精确指向本次安装目录的计划任务，避免留下指向已删除程序的任务，也不会误删另一安装路径的任务。

配置凭据和日志会分别询问是否删除，两个问题均默认选择“否”。明确选择删除后，只处理当前执行卸载的 Windows 账户的 `%LOCALAPPDATA%\CampusPortalAutoLogin`，并在删除前校验规范绝对路径、拒绝数据目录或日志目录为重解析点。使用另一管理员账户通过 UAC 卸载时，原使用者的数据不会处理，必须由相应用户自行删除。删除失败会提示需要手动检查的准确目录。

## 验收要求

构建测试和隔离预览不能替代真实网络验证。发布前必须在目标校园网手工验收：首次运行、保存设置、立即登录、断网恢复、网络变化触发、定时触发、开机登录启动、升级和卸载。

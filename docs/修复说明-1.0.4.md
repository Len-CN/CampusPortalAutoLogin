# 1.0.4 修复门户登录令牌缺失

2026-11-04 至 2026-11-05 的现场日志显示，门户首页、pageInfo、getServices 和 login 均返回 HTTP 200，但认证结果反复为 `page expired, please login again`。用户确认随后联网来自网页手动登录。

只读检查当前门户发现，pageInfo 返回非空的 loginToken，当前 AuthInterFace.js 将其单次 encodeURIComponent 后附加到登录请求。程序原先未读取和提交该字段，导致与当前网页协议不一致。

现在每轮认证从本轮 pageInfo 获取令牌，单次编码后随登录请求提交；不返回令牌的旧门户保持原有请求字段。令牌不持久化，日志脱敏显式覆盖 loginToken。

回归用例覆盖令牌解析、单次编码（含特殊字符）、连续两轮刷新、旧门户兼容及日志脱敏。未使用真实账号提交认证，恢复联网仍需在未登录的校园网环境中验收。

验证结果：Release 构建 0 警告、0 错误；默认核心及协议测试 38 项全部通过；win-x64 自包含发布成功，应用版本为 1.0.4。

# 1.0.2 · 夜航玻璃与 StyleKit 动效

参考：2026-09-23 更新的 `stylekit-design-kit/风格.txt`、`DESIGN_SPEC.md` 及三个动画源码。目录里实际文件名为 `风格.txt`，未发现另名 `参考风格.txt`，本次按该文件执行。

## 材质

- 深墨夜景 + 月光/钢蓝/克制暖光三处大半径光源；光源采用径向衰减与 60 DIP 模糊，颜色在场景层预计算 180% 饱和增强。
- 面板使用低透明度中性白叠层，采样窗口内的模糊光源，加入顶边高光、底边暗缘与外层深阴影。输入框也使用无色半透明表面。
- 随机细颗粒纹理叠层 2.5%，取代早期规则光斑纹理。
- 主操作与标题高亮使用香槟金；普通选择框与边框保持中性。窗口底层保留用户确认的约 82% 不透明度。
- 保持自绘标题栏、无分割连续背景和细滚动条，卡片为 24 DIP 圆角、主要控件为 16 DIP 圆角。

WPF 的实现是对应用内场景进行取光与模糊采样，不是 CSS backdrop-filter，也没有读取桌面截图。窗口外背景仍为半透明透出，不宣称实现系统 Acrylic 或对其它应用实时模糊。

## 三种新增动效

| StyleKit | WPF 实现 |
| --- | --- |
| Text Gradient Flow | 标题前景在月光白与香槟金之间以 3 秒往复流动 |
| Cursor Aura | 独立不接收输入的覆盖层、34 DIP 中性白径向光晕，随指针移动，离开隐藏 |
| Border Beam | 细光带沿圆角卡片/状态区边缘运行，4 秒一圈，保留渐弱尾迹 |

示例代码的紫粉渐变与风格禁止项冲突，因此保留动画方式、按夜航配色适配。背景原有慢速漂移继续保留。背景和标题保持低功耗更新；根据用户反馈，边缘扫光取消 24fps 限制，跟随 WPF CompositionTarget.Rendering 逐帧更新，采用 80 段平滑尾迹及预先冻结的画笔以降低每帧分配。实际帧率由显示刷新率、WPF 和设备性能决定；最小化、隐藏或减少动画时暂停，关闭时移除渲染订阅。

## 验证

- 核心/协议 32 项回归测试；无认证协议修改。
- WPF 实际窗口创建、三种动效挂载、标题渐变位置变化、指针光晕显示/隐藏、最小化暂停/还原恢复、标题栏按钮和日志筛选检查。
- 设置及日志窗口渲染检查，输出 100%/125%/150% 像素预览。像素预览不替代跨显示器实机 DPI 验收。
- 独立审查发现的 ComboBox 焦点边框绑定、高对比度弹层/主按钮文字资源已修正。系统高对比度与减少动画的实际设置切换仍可在目标设备复核。
